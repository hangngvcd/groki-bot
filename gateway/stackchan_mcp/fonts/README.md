# Glyph display fonts

These font files are bundled **unmodified** for the local 生字 display. Each
character uses Free HK Kai when covered, otherwise Noto Sans HK.

- `FreeHKKai-4700.ttf`: Free HK Kai 自由香港楷書, 4700-character edition,
  Version 1.00. Downloaded as `Free-HK-Kai_4700.ttf` from the `download` branch
  of [freehkfonts/freehkkai](https://github.com/freehkfonts/freehkkai).
  © its authors / freehkfonts, licensed under
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
  See `FreeHKKai-LICENSE.txt` and the complete upstream acknowledgements in
  `FreeHKKai-Notice-for-Use.txt`.
- `NotoSansHK-Regular.otf`: Noto Sans HK, © Google/Adobe, licensed under SIL
  Open Font License 1.1. Source:
  [notofonts/noto-cjk](https://github.com/notofonts/noto-cjk),
  `Sans/SubsetOTF/HK/NotoSansHK-Regular.otf`. See `NotoSansHK-OFL.txt`.
